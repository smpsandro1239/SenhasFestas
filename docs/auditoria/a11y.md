# Auditoria de Acessibilidade (A11y)

Última atualização: 2026-09-26

## Cobertura atual

- **Páginas públicas (medidas em browser, axe-core + Playwright em produção):**
  `/auth/login`, `/auth/register`, `/offline`, `/publico`, `/qr-order?event=E2E`.
- **Páginas autenticadas (analisadas estaticamente, NÃO medidas em browser):**
  `/pedidos`, `/perfil`, `/admin`, `/relatorios`, `/caixa`, `/cozinha`, `/pos`.

## Limitação conhecida

**O scan em browser das páginas staff (caixa, cozinha, pos, relatorios, admin) não foi
medido.** Não existe ambiente isolado disponível: sem Docker, sem Redis/Postgres local, e
o `backend/.env` aponta para a Neon de produção — não se subiu o backend contra produção
nem se usou credencial de acesso para as medir. A análise dessas páginas é apenas estática
(cor no código + fundo efetivo do container + cálculo de contraste WCAG).

## Estado do fix

- `text-brand` → `text-brand-light` (`#60a5fa`: 6.97:1 no `surface-solid`, 6.29:1 no auth):
  pilot em `/auth/login:79` + `/auth/register:119` (`2aadf00`, axe = 0 violações) e os
  8 estáticos `cozinha:251/268`, `pos:171`, `relatorios:143`, `page:177`,
  `qr-order:188/234`, `mobile-nav:44` (`37fce0c`).
- `tabs:47` (underline): não usado hoje, mantido como está (revertido em `4c4aceb`).
- Avatares (`admin:407/494`, `perfil:56`): ronda visual separada — candidatos a letra
  `text-zinc-100` **ou** escurecer gradiente (`from-brand/40 to-brand/20`) mantendo a marca.
- `publico:35`: mantido `text-brand` (é large — min clamp 24px bold — e o ecrã TV é de marca).

Metodologia de medição: fundos compostos calculados (rgba sobre base) + contraste WCAG 2.2
(relação de luminâncias). Os pares de `/auth/*` foram também medidos diretamente pelo axe.
